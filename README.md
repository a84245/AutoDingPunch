# 自动打卡助手 (AutoDingPunch)

一个 Android 应用：**到达公司自动打开钉钉完成上班打卡，离开公司自动完成下班打卡**，解决忘记打卡的问题。

> ⚠️ **重要声明**：本工具通过系统无障碍服务自动操作钉钉 UI，**可能违反公司考勤制度或钉钉用户协议**，存在被公司制度处罚、钉钉风控识别（如异常打卡提醒）的风险。请务必先与公司确认合规性，自行承担使用风险。本工具仅供个人学习研究 Android 无障碍与定位开发。

---

## 功能

- 📍 **地理围栏监测**：设置公司位置和半径（默认 300 米），进入半径触发上班打卡，离开半径触发下班打卡
- 🤖 **自动操作钉钉**：通过无障碍服务自动打开钉钉 → 进入工作台 → 打开考勤打卡 → 点击打卡按钮
- 🛡️ **防重复打卡**：页面已显示"已打卡"时自动跳过，不会重复点击
- 🚫 **外勤保护**：检测到"外勤打卡"/"不在打卡范围"时直接放弃，绝不执行外勤打卡
- 🔋 **监测时段（省电）**：可设置上班/下班两个监测窗口，窗口外暂停定位，到点自动恢复
- 🔔 **结果通知**：打卡成功/失败都会发通知提醒，可在应用内查看完整日志
- ⚡ **手动触发**：应用内可一键"立即上班打卡 / 立即下班打卡"，用于测试
- 🔄 **开机自启**：手机重启后自动恢复监测
- 📊 **打卡日志**：记录最近 100 条打卡记录（时间、类型、结果）

## 工作原理

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────────┐
│ 前台服务     │     │ 无障碍服务        │     │ 钉钉            │
│ 监听 GPS    │────▶│ 状态机自动操作 UI │────▶│ 完成打卡         │
└─────────────┘     └──────────────────┘     └─────────────────┘
  进入/离开围栏        打开钉钉 → 工作台           按钮点击
  （滞回判断防抖）      → 考勤打卡 → 打卡按钮
```

- **位置判断**：GPS 定位每 30 秒更新一次；进入按半径判断，离开按 `半径 × 1.3` 判断（滞回区间防止 GPS 抖动导致反复打卡）；同一类型打卡有 60 分钟冷却时间。
- **无障碍操作**：状态机依次查找并点击「工作」Tab →「考勤打卡」入口 → 打卡按钮（上班/下班），支持页面已就绪时跳过步骤、滚动查找、确认弹窗处理，60 秒超时保护。
- **状态保护**：每次读取页面时先做两层检查——① 页面出现"已打卡"则判定已打过卡，记录"已跳过"并结束，绝不重复点击；② 考勤页面出现"外勤打卡"/"不在打卡范围"则判定不在打卡范围，记录"已跳过"并结束。点击后若弹出外勤打卡确认框也会自动放弃，本工具只执行正常打卡。
- **监测时段（省电）**：默认全天监测（30 秒定位一次）。可在「监测时段」卡片开启时段限制并分别设置上班/下班两个监测窗口（如上班 07:00-09:30、下班 17:30-20:00，支持跨天）。开启后仅在窗口内定位；窗口外暂停 GPS 并自动设定闹钟，到下一个窗口开始时间自动恢复监测，通知栏会显示"监测暂停（省电）HH:mm 自动恢复"。

## 构建方法

需要安装 [Android Studio](https://developer.android.com/studio)（自带 JDK 和 Android SDK）。

1. 打开 Android Studio → `Open` → 选择本目录 `AutoDingPunch`
2. 等待 Gradle 同步完成（首次需下载依赖，请保持网络通畅）
3. 连接手机（开启 USB 调试），点击 Run ▶ 安装到手机
4. 或菜单 `Build → Build APK(s) → Build APK(s)`，生成 APK 在 `app/build/outputs/apk/debug/`

**最低系统要求**：Android 8.0 (API 26)

## 使用步骤（首次配置）

打开应用后，按界面从上到下的顺序依次配置：

### 1. 设置公司位置
- 在**公司门口/工位上**点击「📍 用当前定位设置公司位置」
- 调节围栏半径（建议 150~300 米）
- 也可手动输入经纬度（高德/百度地图上长按即可查看坐标）

### 2. 开启 4 项权限（按界面提示依次点击）

| 权限 | 说明 | 操作 |
|---|---|---|
| ① 定位权限 | 获取位置 | 点击按钮授权 |
| ② 后台定位 | Android 10+ 必须选 **"始终允许"** | 按提示去设置页 |
| ③ 无障碍服务 | 自动操作钉钉 | 去无障碍设置 → 找到"自动打卡辅助服务"→ 开启 |
| ④ 电池优化豁免 | 防止系统杀后台导致不监测 | 点击按钮选择"允许" |

> 💡 小米/华为等品牌手机建议额外在系统设置中把本应用加入「自启动白名单」和「后台运行白名单」。

### 3. 开始监测
- 返回应用，点击「**开始监测**」
- 通知栏会出现常驻监测通知（含"立即上班/立即下班/停止"快捷按钮）
- 先点「手动打卡」区的按钮测试无障碍流程能否正常操作钉钉

### 4. 验证
- 上班时间：走进公司 → 手机会自动打开钉钉并打卡 → 收到"上班打卡 成功"通知
- 下班时间：走出公司 → 自动打卡 → 收到"下班打卡 成功"通知
- 应用内「打卡日志」可查看每次记录

## 常见问题

**Q: 提示"未开启无障碍服务"？**
去手机「设置 → 无障碍 → 已下载服务」中找到"自动打卡辅助服务"并开启。部分手机（如小米）还需要开启"无障碍服务"总开关。

**Q: 钉钉版本更新后打不了卡？**
钉钉 UI 变化会导致找不到按钮。先点"调试：仅打开钉钉"确认钉钉能正常打开，再用"立即上班打卡"测试。若仍失败，请在应用日志中查看是哪一步超时。

**Q: 一直不触发打卡？**
检查：① 公司位置是否设置正确 ② 后台定位是否"始终允许" ③ 电池优化是否豁免 ④ 是否在冷却期（60 分钟）内。

**Q: 会自动打卡但钉钉提示异常？**
钉钉对打卡地点/行为有风控，频繁非正常操作可能触发人脸识别或异常提醒。请谨慎使用。

**Q: 手机锁屏后还能监测吗？**
能。前台服务 + 后台定位权限已保证锁屏后继续定位。但部分国产 ROM 强制杀后台，务必完成第 ④ 步电池优化豁免。

**Q: 想省电，只在上下班时段监测？**
去「监测时段（省电）」卡片打开开关，设置上班/下班两个监测窗口（如 07:00-09:30、17:30-20:00），点「保存时段设置」。窗口外会暂停定位（通知栏显示"监测暂停（省电）"），到点自动恢复。关闭开关则回到全天监测。

```

├── app/src/main/
│   ├── java/com/autoding/punch/

│   │   └── values/  (strings/colors/themes)
│   └── AndroidManifest.xml
└── build.gradle 等 Gradle 配置
```
