# 考勤提醒助手 (AutoDingPunch)

一个 Android 应用：**到达公司 / 离开公司时自动弹通知提醒您手动去钉钉打卡**，解决忘记打卡的问题。

> ℹ️ **产品形态说明**：本工具**只做位置提醒，不自动操作任何应用**（无无障碍服务、不模拟点击）。到达/离开公司围栏后，手机收到一条高优先级通知，您点开通知即可直接进入钉钉完成打卡。请遵守公司考勤制度，按时手动打卡。

---

## 功能

- 📍 **地理围栏监测**：设置公司位置和半径（默认 300 米），进入半径触发「上班提醒」，离开半径触发「下班提醒」
- 🔔 **高优先级提醒通知**：到/离公司时弹通知，点击通知可直接打开钉钉 App，方便手动打卡
- 🛡️ **防重复提醒**：同一状态有 60 分钟冷却，GPS 抖动不会反复弹提醒（滞回判断 + 冷却）
- 🔋 **监测时段（省电）**：可设置上班/下班两个监测窗口，窗口外暂停定位，到点自动恢复
- 🔄 **开机自启**：手机重启后自动恢复监测
- 📊 **提醒日志**：记录最近 100 条提醒记录（时间、类型、结果）
- ⚡ **提醒测试**：应用内可一键「测试上班提醒 / 测试下班提醒」，验证通知是否正常
- 🚀 **快捷打开钉钉**：一键直达钉钉 App，用于手动打卡

## 工作原理

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────────┐
│ 前台服务     │     │ 高优先级通知      │     │ 钉钉（手动）     │
│ 监听 GPS    │────▶│ 到/离公司提醒     │────▶│ 您点开通知去打卡  │
└─────────────┘     └──────────────────┘     └─────────────────┘
  进入/离开围栏        点击通知直达钉钉
  （滞回判断防抖）
```

- **位置判断**：GPS 定位每 30 秒更新一次；进入按半径判断，离开按 `半径 × 1.3` 判断（滞回区间防止 GPS 抖动导致反复提醒）；同一类型提醒有 60 分钟冷却时间。
- **提醒方式**：命中围栏后发送一条高优先级通知「记得上班打卡啦 / 记得下班打卡啦」，点击通知优先打开钉钉 App（若已安装），未安装则打开本应用。
- **监测时段（省电）**：默认全天监测（30 秒定位一次）。可在「监测时段」卡片开启时段限制并分别设置上班/下班两个监测窗口（如上班 07:00-09:30、下班 17:30-20:00，支持跨天）。开启后仅在窗口内定位；窗口外暂停 GPS 并自动设定闹钟，到下一个窗口开始时间自动恢复监测，通知栏会显示「监测暂停（省电）HH:mm 自动恢复」。

## 构建方法

需要安装 [Android Studio](https://developer.android.com/studio)（自带 JDK 和 Android SDK）。

1. 打开 Android Studio → `Open` → 选择本目录 `AutoDingPunch`
2. 等待 Gradle 同步完成（首次需下载依赖，请保持网络通畅）
3. 连接手机（开启 USB 调试），点击 Run ▶ 安装到手机
4. 或菜单 `Build → Build APK(s) → Build APK(s)`，生成 APK 在 `app/build/outputs/apk/debug/`

**最低系统要求**：Android 8.0 (API 26)

## 使用步骤（首次配置）

打开应用后，按界面从上到下的顺序依次配置：

### 1. 设置公司位置
- 在**公司门口/工位上**点击「📍 用当前定位设置公司位置」
- 调节围栏半径（建议 150~300 米）
- 也可手动输入经纬度（高德/百度地图上长按即可查看坐标）

### 2. 开启 3 项权限（按界面提示依次点击）

| 权限 | 说明 | 操作 |
|---|---|---|
| ① 定位权限 | 获取位置 | 点击按钮授权 |
| ② 后台定位 | Android 10+ 必须选 **"始终允许"** | 按提示去设置页 |
| ③ 电池优化豁免 | 防止系统杀后台导致不监测 | 点击按钮选择「允许」 |

> 💡 小米/vivo/华为等品牌手机建议额外在系统设置中把本应用加入「自启动白名单」和「后台运行白名单」。

### 3. 开始监测
- 返回应用，点击「**开始监测**」
- 通知栏会出现常驻监测通知
- 先点「提醒测试与快捷操作」区的按钮，验证能否正常弹出提醒通知

### 4. 验证
- 上班时间：走进公司 → 手机收到「记得上班打卡啦」通知 → 点开通知进钉钉打卡
- 下班时间：走出公司 → 收到「记得下班打卡啦」通知 → 点开通知进钉钉打卡
- 应用内「打卡日志」可查看每次提醒记录

## 常见问题

**Q: 一直不触发提醒？**
检查：① 公司位置是否设置正确 ② 后台定位是否「始终允许」 ③ 电池优化是否豁免 ④ 是否在冷却期（60 分钟）内 ⑤ 是否落在监测时段窗口内（若开启了时段限制）。

**Q: 通知没弹出？**
确认已授予「通知权限」（Android 13+ 需在系统设置中允许本应用发送通知）。提醒通知为高优先级，正常情况下会横幅 + 响铃。

**Q: 手机锁屏后还能监测吗？**
能。前台服务 + 后台定位权限已保证锁屏后继续定位。但部分国产 ROM 强制杀后台，务必完成第 ③ 步电池优化豁免。

**Q: 想省电，只在上下班时段监测？**
去「监测时段（省电）」卡片打开开关，设置上班/下班两个监测窗口（如 07:00-09:30、17:30-20:00），点「保存时段设置」。窗口外会暂停定位（通知栏显示「监测暂停（省电）」），到点自动恢复。关闭开关则回到全天监测。

**Q: Android 14 上打开就闪退？**
请更新到最新 Release。早期版本存在 `registerReceiver` 未声明导出性的闪退问题，已修复。通知权限弹窗也改为只弹一次。
